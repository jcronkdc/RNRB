# NextRecord Light Theme - Color Palette Analysis

**Source**: https://preview.themeforest.net/item/nextrecord-recording-sound-studio-elementor-template-kit/full_screen_preview/31732775

**Analysis Date**: December 3, 2025

## Extracted Color Palette

### Primary Colors

- **Primary Accent/Brand Orange**: `#FF6600`
  - Used for: Buttons, links, icons, hover states, "record" text in logo
  - This is the signature color of the theme

- **Secondary Orange**: `#FCBC45`
  - Used for: Subtle accents, gradients (less prominent than #FF6600)

### Background Colors

- **Pure White**: `#FFFFFF`
  - Used for: Main backgrounds, cards, buttons (secondary), social icons

- **Dark Background**: `#121212`
  - Used for: Dark sections, hero background overlays

- **Near Black**: `#1C1B1F`
  - Used for: Primary text on light backgrounds, headings

### Text Colors

- **Primary Text (Dark)**: `#1C1B1F`
  - Used for: Main headings, titles

- **Secondary Text (Gray)**: `#888888`
  - Used for: Body text, descriptions

- **Tertiary Text (Light Gray)**: `#B1B1B1`
  - Used for: Muted text, secondary information

- **Subtle Text**: `#DADADA`
  - Used for: Very light text on dark backgrounds

- **Light Text**: `#E5E5E5`
  - Used for: Text on dark backgrounds

### Utility/Effect Colors

- **Pure Black**: `#000000`
  - Used for: Deep shadows, overlays

- **Medium Gray**: `#383838`
  - Used for: Borders, dividers

### Semi-Transparent Variations

- **White with Opacity**:
  - `#FFFFFF00` (fully transparent)
  - `#FFFFFF38` (22% opacity)
  - `#FFFFFF4F` (31% opacity)

- **Orange with Opacity**:
  - `#FD9E0100` (fully transparent)
  - `#02010100` (fully transparent)

## Color Usage Breakdown

### Navigation & Header

- Background: `#121212` (dark) or `#FFFFFF` (light)
- Logo text "Next": `#FFFFFF` (white)
- Logo text "record": `#FF6600` (orange)
- Menu icon: `#FF6600` (orange)

### Hero Section

- Background: Dark image with `#121212` overlay
- Main heading: `#FFFFFF` (white)
- Background text: Semi-transparent white

### Content Sections (Light)

- Background: `#FFFFFF` (white)
- Headings: `#1C1B1F` (near black)
- Body text: `#888888` (gray)
- Icons: `#FF6600` (orange) outline style
- Links/CTAs: `#FF6600` (orange)

### Buttons

- **Primary Button**:
  - Background: `#FF6600` (orange)
  - Text: `#FFFFFF` (white)
  - Hover: Inverted or darker orange

- **Secondary Button**:
  - Background: `#FFFFFF` (white)
  - Text: `#FF6600` (orange)
  - Border: `#FF6600` (orange)
  - Hover: Background becomes `#FF6600`, text becomes `#FFFFFF`

### Social Icons

- Default:
  - Background: `#FFFFFF` (white)
  - Icon: `#FF6600` (orange)
- Hover:
  - Background: `#FF6600` (orange)
  - Icon: `#FFFFFF` (white)

## Typography

- **Headings Font**: Oswald (from Google Fonts)
  - Weights: 100-900 available
  - Primary usage: Bold, uppercase style

- **Body Font**: Heebo (from Google Fonts)
  - Weights: 100-900 available
  - Primary usage: Regular weight for body text

## Design Patterns

1. **Contrast**: Strong use of `#FF6600` orange against white backgrounds
2. **Simplicity**: Minimal color palette focused on orange + grayscale
3. **Icons**: Outline style icons in orange (`#FF6600`)
4. **Hover Effects**: Color inversion on buttons (white → orange, orange → white)
5. **Shadows**: Subtle dark shadows using transparent black
6. **Spacing**: Clean, modern spacing with clear visual hierarchy

## Implementation Notes

For the CronkWaters light theme implementation:

- Use `#FF6600` as the primary brand/accent color
- Use `#1C1B1F` for primary text
- Use `#888888` for secondary/body text
- Use `#FFFFFF` for backgrounds and cards
- Maintain the high contrast orange-on-white aesthetic
- Apply the color inversion pattern for interactive elements
