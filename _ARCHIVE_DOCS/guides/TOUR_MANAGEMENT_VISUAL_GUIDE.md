## 🎯 USER JOURNEY

### Creating a Tour:

```
1. Click "+ New Tour" button
   ↓
2. Fill tour details (name, dates, description)
   ↓
3. Click "Create Tour"
   ↓
4. Redirected to tour detail page
   ↓
5. Add shows to tour
   ↓
6. View analytics as data grows
```

### Optimizing Routing:

```
1. Open tour detail page
   ↓
2. Click "Routing" tab
   ↓
3. View current routing metrics
   ↓
4. See optimization suggestions
   ↓
5. Click "Apply Optimized Routing"
   ↓
6. Save updated show order
```

### Exporting Data:

```
1. Open tour detail page
   ↓
2. Click "Export ▼" button
   ↓
3. Choose format (CSV or JSON)
   ↓
4. File downloads instantly
   ↓
5. Open in Excel/text editor
```
